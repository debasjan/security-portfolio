# 🧰 Tools

Custom scripts automating repetitive parts of lab work.
Even a small script with a solid README says more than a paragraph on a CV.

## Ideas to start with (simplest first)
- A recon wrapper (nmap → parsing → follow-up suggestions)
- An enum helper (automate the first steps per service)
- A simple notes/screenshot organizer per target

## Rule
Original script > fork. Every tool gets its own README:
what it does, how to run it, an example.
